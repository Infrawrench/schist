# INDD spike specimens

These are document data, acquired under the user's 2026-09-29 authorization.
No Adobe SDK headers, executable binaries or decompilation are involved.
No production INDD codec is enabled by having these files.

## Proof

Kenneth Ormandy's [Proof type-proofing template](https://github.com/kennethormandy/proof),
commit `d08584512fc76a8582cf8633f654414e30ba8d9a`, supplies `proof.indd`
and `proof.idml` together. Downloaded 2026-09-29. The repository is MIT
licensed; its notice is preserved in `proof/LICENSE.md`. Exact URLs, sizes
and SHA-256 digests are in `proof/source.json`. No fonts were downloaded.

The two files share a repository and basename. Their semantic equivalence
has not yet been verified. This 2014–2015-era template does not establish
coverage for InDesign v18–v21; more versioned pairs and controlled changes
are needed for the Phase 0 decision.

## Penn State journal templates

Jules (Julian) Luck's public-domain [Academic Style 2](https://zenodo.org/records/15800442)
and [Literary](https://zenodo.org/records/15800497) templates are redistributed
under the publisher's CC0 dedication. Each directory includes its IDML/INDD/PDF,
license notice, exact source URLs and hashes, and the read-only INDD probe result.
Both metadata streams identify InDesign 20.2 on Windows. No fonts or font caches
were downloaded. The IDML tests exercise seven/eight-page facing documents,
populated two-sheet parents, repeated saves and the academic template's spot ink.
Table, footnote, math and anchored-content fidelity are not established.

## OAC Creator 2025

Four additional InDesign 19.5 pairs were downloaded from OAC's public template
archive. Only provenance and probe metadata are retained in `oac2025/`; its README
explains reproduction and the redistribution limitation. Those samples include
Japanese prose and populated facing masters. Together with Proof and Penn State,
there are seven acquired pairs, three redistributed here. Version 18/21 and
controlled one-property changes remain missing. None decodes the INDD database.


## OAC Creator 2027

Four additional pairs from OAC's September 2026 template release also identify
**InDesign 19.5**, despite the publication date. `oac2027/` contains provenance and
probe metadata only; document redistribution terms remain unverified. The acquired
corpus now contains eleven pairs, with the same three redistributed here. The
v18/v21 and controlled-change gaps remain; no production gate changes.
