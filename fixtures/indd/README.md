## Proof

Kenneth Ormandy's [Proof type-proofing template](https://github.com/kennethormandy/proof),
commit `d08584512fc76a8582cf8633f654414e30ba8d9a`, supplies `proof.indd`
and `proof.idml` together. Downloaded 2026-09-29. The repository is MIT
licensed; its notice is preserved in `proof/LICENSE.md`. Exact URLs, sizes
and SHA-256 digests are in `proof/source.json`. No fonts were downloaded.

The two files share a repository and basename. Their semantic equivalence
has not yet been verified. This 2014–2015-era template does not establish
coverage for InDesign v18–v21; more versioned pairs and controlled changes
are needed for the Phase 0 decision.
